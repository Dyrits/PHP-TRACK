# PHP Track

Solutions to the [Exercism PHP track](https://exercism.org/tracks/php) exercises.

## About The Project

This repository gathers work on the dedicated PHP track on [Exercism](https://exercism.org/), one directory per exercise: hamming, hello-world, resistor-color, reverse-string, simple-cipher, tournament.

From the original README: a legacy repository is available at [-ARCHIVE-EXERCISM](https://github.com/Dyrits/-ARCHIVE-EXERCISM/tree/master/php).

## Built With

- PHP

## Getting Started

Each exercise lives in its own directory, following the structure provided by Exercism (including its tests).
